# Zinc 0.8.4

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.8.4-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.8.4.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.8.4.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.8.4-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.8.4-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

- **Faster interactive echo.** Small terminal responses arriving within 50 ms of
  user input bypass the normal 16 ms output batching delay.
- **Active tab priority.** Background terminal output is parsed in small,
  round-robin slices instead of feeding every xterm instance at full speed.
  The active tab takes priority, while each terminal's output remains ordered.
- **Less repeated binding work.** Unchanged Claude session-binding files reuse
  cached file contents and parsed records instead of being read again on each
  session snapshot.
- **Session saves with less blocking.** Running-session snapshots are written
  through an asynchronous serial queue. A renderer reload saves synchronously
  before restore so the new renderer does not read an older snapshot; quit also
  retains a synchronous save fallback.
- **Less background process checking.** Hidden tabs recheck their foreground tool
  less often. Switching back to a tab brings any pending check forward to the
  active-tab interval rather than waiting for the longer background timer.
